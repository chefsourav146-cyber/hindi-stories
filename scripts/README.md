# Viral Videos Pipeline

1. Add a script as `scripts/yourname.json` (copy `video1.json`).
2. Push to GitHub. The workflow builds the video automatically.
3. Open the repo > Actions > latest run > Artifacts > download `videos`.
4. Post the MP4 to Shorts, Reels, and TikTok.

Run locally: `pip install -r requirements.txt && python src/make_video.py`
